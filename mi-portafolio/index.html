Sobre mí

¡Hola! Soy Matias un estudiante de 4.º Medio del Colegio El Belloto. Me apasiona la tecnología, la resolución lógica de problemas y el desarrollo de software. A lo largo de la asignatura de Pensamiento Computacional y Programación he desarrollado proyectos en Java, JavaScript, HTML y CSS.

Durante este año he fortalecido habilidades en algoritmos, diseño modular de interfaces web, depuración de errores y buenas prácticas con Git y GitHub. En el futuro me gustaría seguir estudiando carreras relacionadas con la ingeniería informática y el desarrollo web profesional.

Página interactiva según Wireframe

Página web desarrollada a partir de un wireframe de diseño. Resuelve la visualización ordenada de contenidos interactivos mediante eventos en el DOM. Con este trabajo aprendí a estructurar código HTML semántico, aplicar estilos CSS y manipular elementos con JavaScript.

Máquina de bebidas en Java

Aplicación de consola en Java que simula la compra en una máquina expendedora automática. Resuelve el control de stock de productos, ingreso de monedas y cálculo exacto de vuelto. Aprendí a utilizar variables, condicionales if/else, ciclos while y la clase Scanner.

Tecnologías: Java, Scanner, Ciclos, Arreglos, Git

Minijuego: Adivina el Número

Juego donde el usuario debe adivinar un número secreto entre 1 y 10 generado aleatoriamente. Resuelve la validación de intentos y muestra mensajes de pistas (mayor o menor). Aprendí a utilizar Math.random(), eventos de teclado y condicionales para lógica de juego.

Tecnologías: JavaScript, HTML5, CSS3, Math.random
